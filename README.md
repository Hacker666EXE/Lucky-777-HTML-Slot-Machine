# 🎰 Lucky 777

Base demonstrativa de uma máquina caça-níquel de 3 reels, desenvolvida em HTML, CSS e JavaScript.

O projeto possui interface responsiva para mobile e PC, sistema de créditos e apostas, jackpot progressivo, combinações de prêmios, animações dos reels e efeitos sonoros.

## ⚠️ Aviso

Projeto demonstrativo e educacional, sem utilização de dinheiro real ou sistema de apostas.
