# Lucky-777
Base demonstrativa de uma máquina caça-níquel de 3 reels, desenvolvida em HTML, CSS e JavaScript.  O projeto conta com interface responsiva, sistema de créditos e apostas, jackpot progressivo, combinações de prêmios, animações dos reels e efeitos sonoros.  Projeto desenvolvido para demonstração e estudo, sem utilização de dinheiro real.
